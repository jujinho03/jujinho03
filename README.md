# 주진호 | 금융 데이터 분석 · 모형 검증

인하대학교에서 데이터사이언스를 전공하며 금융 데이터 분석·모형 검증 직무를 준비하고 있습니다. 대출 심사에서는 위험점수가 높은 집단에 실제 부도가 얼마나 모이는지, 보험 청구지원 AI에서는 약관을 정확히 인용하고도 잘못된 담보를 안내하는 경우가 있는지 살펴봤습니다.

## 대표 분석

### Home Credit · 어떤 대출 신청을 먼저 검토할까?

학부 팀 과제에서 대출 데이터의 품질 점검과 모형 검증을 맡았습니다. 이후 개인 재분석에서 단위가 다른 변수의 회귀계수를 직접 비교한 오류를 발견해, 표준화 효과와 순열 중요도로 변수의 영향력을 다시 검토했습니다.

층화 홀드아웃에서 위험점수 **상위 10%의 부도율은 26.48%**, 검증 표본 평균의 **3.28배**였습니다. 이 결과를 추가 심사 대상을 정하는 근거로 해석했습니다. 향후 대출의 부도율과 손실 절감 효과는 검증 범위 밖입니다. [모형 검증과 임계값 비교](https://github.com/jujinho03/home-credit-default-risk/blob/c753352f588a20c7f484e25eeb16c61a72364ef6/docs/findings.md)

### 보험펜 · 약관 인용이 맞아도 담보 안내가 틀릴 수 있을까?

FinPoint 4인 팀의 팀장으로 청구지원 평가용 정답 사례를 만들고 안전성과 화면 문구를 검수했습니다. 저장된 분류 예측을 재사용한 합성 개발 평가에서 **40건 중 37건**이 허용 기준을 충족했습니다.

수하물이 늦는지 분실됐는지 아직 모르는 사례에서 AI는 약관 원문을 정확히 인용했지만 지연으로 단정하고 관련 담보와 서류를 안내했습니다. 이 사례는 판단을 보류해야 한다는 평가 기준을 통과하지 못했습니다. [기대값과 실제 응답](portfolio/bohumpen.md#failure) · [내 기여와 팀 구현](portfolio/bohumpen.md#contribution)

### 플랜브릿지 · 첫 급여가 늦어지면 어떤 전략을 권할까?

가상 CPA 수험생의 마지막 응시 기회와 생활비를 함께 고려한 재무 분석입니다. 3인 팀의 팀장으로 18개월 안전자금 하한과 60개월 조건부 할인 현금흐름을 비교하고 권고 조건을 정리했습니다.

기본 가정에서는 취업 전환의 60개월 지표가 가장 높았습니다. **취업 전환의 첫 급여만 3개월 늦추면** 5,968.6만 원으로 근로 병행 기본값 6,062.2만 원 아래로 내려갔습니다. 시간제 계약과 첫 입금을 확인하는 조건으로 근로 병행을 우선 검토했습니다. [전략 비교와 권고](portfolio/planbridge.md#results) · [급여 지연 민감도 원본](https://github.com/jujinho03/afpk-cpa-financial-planning-2026/blob/c78d4f2fec64c52bc9bd8012d4515e47ab8e4abb/outputs/tables/sensitivity.json)

## 다른 분석과 검증

- **KOSPI · 금융 시계열** — 팀 과제의 데이터 검증을 맡고 분석을 개인적으로 재구축했습니다. 수준 회귀의 학습 R²는 0.8103이었지만 잔차 자기상관이 강했고 공적분 근거도 부족했습니다. 1차 차분과 HAC 강건 표준오차를 적용해 결론을 단기 동시점 연관성으로 좁혔습니다. [시계열 진단 보고서](https://github.com/jujinho03/kospi-macro-spurious-regression/blob/ddd4f114fa9fcc9087138b0dbb3f8b20b5ab5cde/docs/findings.md)
- **VeriMod · 한국어 댓글 분류와 판정 기록 검증** — HTTP 451 팀장으로 데이터 분할·누수 점검, R01 오분류 분석과 본선 발표를 맡았습니다. Macro-F1 0.6525는 모델 선택에 사용한 검증 표본 1,255건에서 얻은 값이며 독립 TEST는 봉인 상태입니다. 팀은 별도로 테스트넷 영수증 2건의 기록 무결성을 시연했습니다. [모델 카드](https://github.com/jujinho03/verimod/blob/3e1d97b18ec4d1e0d96d0f951e154d8b3b138c74/docs/model-card.md) · [영수증 검증 기록](https://github.com/jujinho03/verimod/blob/3e1d97b18ec4d1e0d96d0f951e154d8b3b138c74/docs/handoffs/w4-anchored-epoch-public/20261020-r01/README.md)
- **서울시 공공자전거 · 다음 한 시간의 대여 수요** — 팀에서 전처리를 맡은 뒤 GPS 군집 3개와 시간순 검증을 개인적으로 재구축했습니다. 2024년 4분기 동일 테스트 구간에서 LightGBM의 군집 평균 예측 오차(Macro RMSE)는 SARIMA보다 58.6% 낮았습니다. [모형별 예측 오차](https://github.com/jujinho03/seoul-bike-demand-forecasting/blob/acc34adfef41548cd36f3e52ae1397494c40390c/docs/findings.md)
