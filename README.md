# 주진호 | 금융 데이터 분석 · 모형 검증

인하대학교 데이터사이언스 전공. 관심 직무는 금융 데이터 분석과 모형 검증. 대출 위험점수가 실제 부도를 얼마나 구별하는지, 보험 청구지원 AI가 어떤 상황에서 잘못된 담보를 안내하는지 분석했음. 각 결과에 사용한 데이터와 검증 조건, 해석할 수 있는 범위를 함께 기록했음.

## 대표 분석

### Home Credit · 대출 심사 우선순위와 변수 중요도

학부 팀 과제에서 대출 신청 데이터 307,511건의 품질 점검과 모형 검증을 담당했음. 개인 재분석에서 단위가 다른 변수의 회귀계수를 직접 비교한 오류를 확인했음. 표준화 효과와 순열 중요도로 변수의 영향력을 다시 검토했음.

학습·검증 데이터를 80:20으로 층화 분할하고 학습 데이터에서만 결측 대체값과 표준화 기준을 산출했음. 검증 표본에서 L2 로지스틱 회귀의 ROC-AUC는 0.7504. **위험점수 상위 10%의 부도율은 26.48%로 검증 표본 평균의 3.28배**였음. 추가 심사 순서를 정하는 근거로 해석했음. 미래 시점 성능과 실제 대손 절감 효과 검증은 차후 과제. [모형 검증과 임계값 비교](https://github.com/jujinho03/home-credit-default-risk/blob/c753352f588a20c7f484e25eeb16c61a72364ef6/docs/findings.md)

### 보험펜 · 여행자보험 청구지원 AI의 판단 보류

FinPoint 4인 팀장으로 평가용 정답 사례를 작성하고 안전성과 화면 문구를 검수했음. 저장된 분류 예측을 재사용한 합성 개발 평가에서 **40건 중 37건**이 사고 분류·판단 보류·담보 및 서류 연결 등의 복합 허용 기준을 충족했음.

수하물 지연과 분실을 구별할 정보가 부족한 사례(TRV-018)에서 AI가 지연 담보와 필수서류를 안내했음. 인용 2건은 약관 원문과 일치했고, 세부 사고 유형의 판단 보류에는 실패했음. 해당 실패의 수정·재검증 여부는 미확인. [기대값과 실제 응답](portfolio/bohumpen.md#failure) · [개인 기여와 팀 구현](portfolio/bohumpen.md#contribution)

### 플랜브릿지 · 첫 급여 지연에 따른 재무 권고

3인 팀장·재무분석 담당. 마지막 응시 기회를 유지하려는 가상 CPA 수험생의 18개월 월말 잔액을 안전자금 하한과 대조하고, 60개월 조건부 할인 현금흐름으로 전략을 비교했음.

기본 가정에서 취업 전환의 60개월 지표가 가장 높았음. **취업 전환의 첫 급여만 3개월 늦춘 경우**, 지표는 5,968.6만 원으로 근로 병행 기본값 6,062.2만 원을 밑돌았음. 시간제 계약과 첫 입금 확인을 조건으로 근로 병행을 우선 검토했음. 대회 공식 접수·수상 여부는 미확인. [전략 비교와 권고](portfolio/planbridge.md#results) · [급여 지연 민감도 원본](https://github.com/jujinho03/afpk-cpa-financial-planning-2026/blob/c78d4f2fec64c52bc9bd8012d4515e47ab8e4abb/outputs/tables/sensitivity.json)

## 시계열 분석과 AI 검증

- **KOSPI · 금융 시계열 진단** — 팀 과제에서 데이터 검증을 담당했음. 개인 재분석에서 2010~2024년 월별 180개 시점을 구성하고, 재수집한 환율·유가에서 달라진 값 68개를 대조했음. 수준 회귀의 학습 R²는 0.8103. 잔차 자기상관이 강하고 공적분 근거가 부족해 1차 차분과 HAC 강건 표준오차를 적용하고, 해석을 단기 동시점 연관성으로 한정했음. [시계열 진단 보고서](https://github.com/jujinho03/kospi-macro-spurious-regression/blob/ddd4f114fa9fcc9087138b0dbb3f8b20b5ab5cde/docs/findings.md)
- **VeriMod · 한국어 댓글 오분류 분석** — HTTP 451 팀장으로 데이터 분할·누수 점검, R01 오분류 분석과 본선 발표를 담당했음. 모델 선택에 사용한 검증 표본 1,255건에서 Macro-F1은 0.6525. 공격적 표현(offensive) 403건 중 140건을 일반 표현(none)으로 분류했음. 독립 TEST는 봉인·미실행. 팀은 테스트넷 영수증 2건으로 발급 이후 기록의 무결성을 시연했음. [모델 카드](https://github.com/jujinho03/verimod/blob/3e1d97b18ec4d1e0d96d0f951e154d8b3b138c74/docs/model-card.md) · [영수증 검증 기록](https://github.com/jujinho03/verimod/blob/3e1d97b18ec4d1e0d96d0f951e154d8b3b138c74/docs/handoffs/w4-anchored-epoch-public/20261020-r01/README.md)
- **서울시 공공자전거 · 군집별 시간당 대여 수요** — 6인 팀 과제에서 이상치 기준과 전처리를 담당했음. 개인 재분석에서 원천 기록 79,670,647행을 검수하고 GPS 검증을 통과한 대여소 2,847개를 세 군집으로 나눴음. 2024년 4분기 시간순 테스트에서 LightGBM의 군집 평균 예측 오차(Macro RMSE)는 190.724로, 같은 구간의 SARIMA보다 58.6% 낮았음. [모형별 예측 오차](https://github.com/jujinho03/seoul-bike-demand-forecasting/blob/acc34adfef41548cd36f3e52ae1397494c40390c/docs/findings.md)

## 로컬 시연

**PathFit AI · 돌봄과 통근을 고려한 직업훈련 비교**

MergeReady 4인 팀장으로 2026년 10월 2일 고용24 해커톤에 아이디어 기획안과 데이터 활용 명세를 제출했음. 기획서상 생활 제약 지표와 합성 데이터·검증 방법 설계를 분담했음. 11월 21일 합성 채용공고 150건·훈련 과정 26개를 사용하는 로컬 시제품에서 조건 입력, 훈련 비교, What-if 화면을 확인했음. 대회 1차 결과·본선 진출·공개 배포 여부는 미확인.
