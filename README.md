# 주진호 | 금융 데이터 분석 · 모형 검증

인하대학교 데이터사이언스 전공. 관심 직무는 금융 데이터 분석과 모형 검증. 주요 분석 대상은 대출 위험점수의 부도 판별력과 여행자보험 청구지원 AI의 담보 안내 오류. 프로젝트별로 사용한 데이터, 검증 조건, 결과의 해석 범위를 기록.

## 대표 분석

### Home Credit · 대출 심사 우선순위와 변수 중요도

학부 팀 과제에서 대출 신청 307,511건의 데이터 품질 점검과 모형 검증 담당. 개인 재분석 과정에서 단위가 다른 변수의 회귀계수를 직접 비교한 오류 발견. 표준화 효과와 순열 중요도를 기준으로 변수 중요도 해석을 교정.

학습·검증 데이터를 80:20으로 층화 분할하고, 결측 대체값과 표준화 기준은 학습 데이터에서만 산출. 검증 표본에서 L2 로지스틱 회귀의 ROC-AUC는 0.7504. **위험점수 상위 10%의 부도율은 26.48%로, 검증 표본 평균의 3.28배.** 이 결과의 활용 범위는 추가 심사 대상의 우선순위 검토. 미래 시점 성능과 실제 대손 절감 효과 검증은 차후 과제. [모형 검증과 임계값 비교](https://github.com/jujinho03/home-credit-default-risk/blob/c753352f588a20c7f484e25eeb16c61a72364ef6/docs/findings.md)

### 보험펜 · 여행자보험 청구지원 AI의 판단 보류

FinPoint 4인 팀장으로 평가용 정답 사례 작성, 안전성 평가와 화면 문구 검수 담당. 저장된 분류 예측을 재사용한 합성 개발 평가에서 **40건 중 37건**이 사고 분류·판단 보류·담보 및 서류 연결 등의 복합 허용 기준 충족.

수하물 지연과 분실을 구별할 정보가 부족한 사례(TRV-018)에서 AI가 지연 담보와 필수서류를 안내. 약관 인용 2건은 원문과 일치했으나 세부 사고 유형의 판단 보류에는 실패. 해당 오류의 수정·재검증 여부는 미확인. [기대값과 실제 응답](portfolio/bohumpen.md#failure) · [개인 기여와 팀 구현](portfolio/bohumpen.md#contribution)

### 플랜브릿지 · 첫 급여 지연에 따른 재무 권고

3인 팀장으로 가상 CPA 수험생의 재무분석 담당. 마지막 응시 기회를 유지하려는 고객을 위해 18개월 월말 잔액을 안전자금 하한과 대조하고, 60개월 조건부 할인 현금흐름을 기준으로 전략을 비교.

기본 가정에서는 취업 전환의 60개월 지표가 1위. **취업 전환의 첫 급여만 3개월 늦추면** 5,968.6만 원으로 근로 병행 기본값(6,062.2만 원)보다 낮은 수준. 시간제 계약과 첫 입금 확인을 조건으로 근로 병행 우선 검토를 권고. 대회 공식 접수·수상 여부는 미확인. [전략 비교와 권고](portfolio/planbridge.md#results) · [급여 지연 민감도 원본](https://github.com/jujinho03/afpk-cpa-financial-planning-2026/blob/c78d4f2fec64c52bc9bd8012d4515e47ab8e4abb/outputs/tables/sensitivity.json)

## 시계열 분석과 AI 검증

- **KOSPI · 금융 시계열 진단** — 팀 과제에서 데이터 검증 담당. 개인 재분석에서 2010~2024년 월별 180개 시점을 구성하고, 재수집한 환율·유가에서 달라진 값 68개를 대조. 수준 회귀의 학습 R²는 0.8103. 강한 잔차 자기상관과 불충분한 공적분 근거를 고려해 1차 차분과 HAC 강건 표준오차를 적용. 해석 범위는 같은 달 금융 변수 변화 사이의 연관성. [시계열 진단 보고서](https://github.com/jujinho03/kospi-macro-spurious-regression/blob/ddd4f114fa9fcc9087138b0dbb3f8b20b5ab5cde/docs/findings.md)
- **VeriMod · 한국어 댓글 오분류 분석** — HTTP 451 팀장으로 데이터 분할·누수 점검, R01 오분류 분석과 본선 발표 담당. 모델 선택에 사용한 검증 표본 1,255건에서 Macro-F1은 0.6525. 공격적 표현(offensive) 403건 중 140건을 일반 표현(none)으로 오분류. 독립 TEST는 봉인·미실행. 팀은 테스트넷 영수증 2건으로 발급 이후 기록의 무결성을 시연. [모델 카드](https://github.com/jujinho03/verimod/blob/3e1d97b18ec4d1e0d96d0f951e154d8b3b138c74/docs/model-card.md) · [영수증 검증 기록](https://github.com/jujinho03/verimod/blob/3e1d97b18ec4d1e0d96d0f951e154d8b3b138c74/docs/handoffs/w4-anchored-epoch-public/20261020-r01/README.md)
- **서울시 공공자전거 · 군집별 시간당 대여 수요** — 6인 팀 과제에서 이상치 기준 수립과 전처리 담당. 개인 재분석에서 원천 기록 79,670,647행을 검수하고 GPS 검증을 통과한 대여소 2,847곳을 세 군집으로 분류. 2024년 4분기 시간순 테스트에서 LightGBM의 군집 평균 예측 오차(Macro RMSE)는 190.724. 같은 구간의 SARIMA 대비 58.6% 감소. [모형별 예측 오차](https://github.com/jujinho03/seoul-bike-demand-forecasting/blob/acc34adfef41548cd36f3e52ae1397494c40390c/docs/findings.md)

## 로컬 시연

**PathFit AI · 돌봄과 통근을 고려한 직업훈련 비교**
